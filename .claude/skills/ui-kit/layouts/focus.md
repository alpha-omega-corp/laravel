# focus

One narrow column, a progress indicator, and nothing else. For onboarding, checkout
and wizards.

## Shell

`layout/containers/05-*`

## Suits

onboarding, checkout, wizards

## Regions

What a roll places in each region of this layout's stub, and what each region is.

- header: the step's title and how far along it is, at the top of one 36rem column
- header — progress, page-heading
- main: one task, in the same narrow column
- main — form-layout | sign-in | input + input + select + button | radio-group + button | description-list + action-panel | calendar + form-layout, prefabs
