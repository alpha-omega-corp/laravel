# locanda

Terracotta on a flour-white page, a mozzarella-butter highlight and an espresso dark, in a round geometric face over Inter, with panels that lift off the page. A pizzeria's own menu.

## Tokens

`[data-palette='locanda']` in `resources/css/themes.css`, which is the one
place they are written. Every colour is a `light-dark()` pair, so this palette
is declared once and answers both schemes — which half applies is the *other*
axis and is not this file's business. See [README.md](README.md).

Taken from a delivery pizzeria's site (pizzalocanda-ch), where it was drawn over
fresh, and kept as it was there. The action is a baked terracotta (`#b4441c`)
with white on it, 5.5:1, never a light orange with black on it, which reads
muddy and cheap; in the dark it barely moves (`#b8461d`, 5.3:1) over the
espresso of the menu's backdrop — the site's own `#c4501e` left hearth's band,
which is the accent, too faint for the soft words set on it. **Text is never the terracotta**: the
accent-strong is the ink itself, because terracotta words read as an alarm, so
the colour is spent on fills — the order button, today's row, a step's dot. The
highlight is a mozzarella butter (`#f3d98b`) with the ink on it, the same in
both schemes, for a flag, a note or the day's offer, so a note never reads as a
button. Outfit at 600 over Inter, a 14px corner on panels and controls alike.

## Mood

Warm, appetising, quick: a menu you order from on your phone.

## Costs

The accent is for fills only: a site that sets links or headings in the
terracotta undoes the palette's one rule. It is a food palette through and
through, and on anything that is not eaten it reads as a menu.
