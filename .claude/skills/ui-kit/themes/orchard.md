# orchard

Deep green on warm paper, with borders that look drawn rather than rendered and hard
offset shadows. Confident, crafted, a little brutalist.

## Tokens

`[data-palette='orchard']` in `resources/css/themes.css`, which is the one
place they are written. Every colour is a `light-dark()` pair, so this palette
is declared once and answers both schemes — which half applies is the *other*
axis and is not this file's business. See [README.md](README.md).

## Mood

Confident, crafted, a little brutalist.
