# lagoon

Teal water and a coral sun on a pale aqua page, airy rounded type, hairline panels with long
soft shadows, and slow, easy movement. Calm, fresh, a holiday.

## Tokens

`[data-palette='lagoon']` in `resources/css/themes.css`, which is the one
place they are written. Every colour is a `light-dark()` pair, so this palette
is declared once and answers both schemes — which half applies is the *other*
axis and is not this file's business. See [README.md](README.md).

## Costs

Its movement is slow on purpose — over a second for a hero — so a screen people work in
feels sluggish in it. Coral is the only warm colour: a page that needs urgency has little to
say it with.
