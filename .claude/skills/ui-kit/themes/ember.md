# ember

Oxblood and gold on warm paper, a high-contrast serif display, near-square corners and buttons
labelled in spaced capitals like a wine list. Warm, luxurious, candlelit.

## Tokens

`[data-palette='ember']` in `resources/css/themes.css`, which is the one
place they are written. Every colour is a `light-dark()` pair, so this palette
is declared once and answers both schemes — which half applies is the *other*
axis and is not this file's business. See [README.md](README.md).

## Costs

The serif display is a single weight, so anything the kit sets in bold in the display face is
synthesised. Its accent is a red, which sits close to the danger colour: an error on an ember
page says so with its icon and its words as well as its hue.
