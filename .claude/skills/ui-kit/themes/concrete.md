# concrete

Poured grey and near-black, one signal orange and the hazard yellow of a barrier, in a condensed heavy face with square slabs. Industrial, exact, loud only where it has to be.

## Tokens

`[data-palette='concrete']` in `resources/css/themes.css`, which is the one
place they are written. Every colour is a `light-dark()` pair, so this palette
is declared once and answers both schemes — which half applies is the *other*
axis and is not this file's business. See [README.md](README.md).

**The yellow is a ground, never a text colour.** On the light canvas it is 1.5:1,
so it carries ink — a badge, a mark, a hazard band — and the orange is the
accent that reads as a link in both schemes. The display face is condensed, so
a title holds half as many characters again on a line as it would in a
grotesque: figures and project numbers are what it sets best, and a long
sentence in it is a wall.

## Costs

Uppercase buttons and a condensed display face shout in a quiet trade: a
practice or a florist drawn in it reads as a depot. In `journal` the heavy
titles fight the narrow column, and a long story wants a face made for reading.
