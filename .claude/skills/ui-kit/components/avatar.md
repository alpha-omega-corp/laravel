# avatar

A person's or a space's mark, their photograph or their initial in a circle, with an optional dot for whether they are there.

## Placement

- workspace.rail — fits: one mark per person or space down the 4rem strip, each the link to it
- console.main — fits: beside the name it stands for, in a row or a heading
- workspace.list — fits: at the start of a row, beside the name of the person it came from
- workspace.detail — fits: beside the chosen item's author
- * — never: a site shows a person as a photograph, in media or features, which a direction draws, and an initial in a circle is an app's

## Behaviour

- It is always given the name it stands for, which is the photograph's alt, the words a screen reader says and the initial drawn without a photograph. (postels-law)
- Outside the rail it goes beside the written name and never replaces it, since a name is recognised where an initial has to be recalled. (working-memory, mental-model)
- A person is round and a team or a space is `square`, the same on every screen. (law-of-similarity, mental-model)
- In the rail each is the link to what it stands for, sized lg or xl so the target reaches 44px. (fittss-law)
- Its status dot is a colour a few pixels wide, so where acting depends on the status, the status is also written beside the name. (von-restorff-effect)
