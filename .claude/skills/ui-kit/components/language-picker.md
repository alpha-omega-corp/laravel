# language-picker

The site's languages, side by side in the header as their codes, FR DE IT EN with the current one in the ink, each named in its own words for a screen reader and on hover, posting the choice to the base, which keeps it and comes back to the same page.

## Placement

- * — never: the site-header draws it by itself, after the theme menu and before its action, when the site binds two languages or more; a page never places it

## Limits

- locales — 6; advice 4 (hicks-law, choice-overload)
- per-page — 1 (jakobs-law)

## Behaviour

- It sits at the far right of the header on every page, where visitors look for it, and nowhere else on the page. (jakobs-law, law-of-common-region)
- Each language is named in itself, Deutsch and not German, so the visitor who cannot read the current one still finds theirs. (mental-model, cognitive-load)
- Every language is in sight as its code, one tap away rather than behind a menu, and never a flag: a flag is a country, and Switzerland alone speaks four of them. (mental-model, cognitive-bias, fittss-law)
- With one language it is not drawn at all, so a single-language site has no control that does nothing. (occams-razor, teslers-law)
- Switching lands on the same page in the new language, never on home, so nothing the visitor was doing is lost. (flow, goal-gradient-effect)
