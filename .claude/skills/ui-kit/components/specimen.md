# specimen

The kit's showcase frame: one component on a plain canvas under its reference, the way the kit's own pages show them.

## Placement

- * — never: it frames a kit component on the kit's own specimen pages, never on a site's page or an app's screen

## Behaviour

- It belongs to the kit's own specimen pages and never to a site or an app, where the component is placed bare. (occams-razor)
- Its caption is the exact reference of the component it frames, `::category/group/name`, since dev mode names the frame by it. (mental-model)
- Its dashed frame and mono caption read as a draft, so a page carrying one reads as unfinished. (aesthetic-usability-effect)
